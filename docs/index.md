# sunbeam-workshop

A starter repository that turns a fresh Ubuntu machine into a named, isolated
OpenStack development workshop - with ready profiles for sunbeam, classic
charmed OpenStack, and Ubuntu packaging work.

- {doc}`tutorial/index` - a hands-on introduction to launching your first workshop
- {doc}`how-to/index` - step-by-step guides for common tasks
